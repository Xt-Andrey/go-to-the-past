## ☁ CAFE AURORA
## Descripción

Cafetería Auroras es un proyecto que simula la gestión y administración de una cafetería moderna y acogedora. Este repositorio contiene el código y los recursos necesarios para manejar el menú, los pedidos, la atención al cliente y la gestión de inventario de manera eficiente.

---

## Características principales

- Gestión dinámica del menú de bebidas y alimentos.  
- Registro y seguimiento de pedidos en tiempo real.  
- Control de inventario para ingredientes y productos.  
- Interfaz sencilla y amigable para usuarios y empleados.  
- Soporte para reportes y estadísticas de ventas.

---

## Objetivo

Facilitar la administración de una cafetería, mejorando la experiencia tanto para los clientes como para los empleados mediante herramientas digitales intuitivas y funcionales.
